# 🔐 Gerador de Senhas em Python

## 📌 Sobre o projeto

Este projeto permite ao usuário criar uma senha aleatória com escolha de tipo de caracteres e tamanho da senha

## ⚙️ Funcionalidades

- Escolher tamanho da senha
- Escolha de tipos de caracteres presentes

## 🛠️ Tecnologias utilizadas

- **Python:** Para lógica de programação
- **Bibliotecas:**
  - `string`
  - `secrets`
  - `time`
  - `sys`

## 💻 Como executar

**Pré-requisitos:**
- Python instalado na máquina.

**Execução:**

1. Clone este repositório:
   ```bash
   git clone https://github.com/ryanprado2109-alt/Gerador-de-senhas-Python.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd gerador de senha python
   ```
3. Execute o programa:
   ```bash
   python main.py
   ```

## 📚 Aprendizados

- Loops de repetição 'for' para incrementação do caractere na senha e para melhoria da UX do terminal
- Tratamento de erros com Try/except
- Utilização de bibliotecas como secrets para a escolha aleatória de caracteres e string para trabalhar com conjuntos de caracteres
